# Вероятностное прогнозирование спроса и оптимизация закупок с использованием интеллектуального агента

**Выпускная квалификационная работа — практическая часть**

Научный руководитель: О. А. Тихонова

## О проекте

Строим рабочий конвейер:

```
данные → вероятностный прогноз спроса → оптимальный объём закупки → агент, объясняющий решение
```

Обычный прогноз даёт одно число: «завтра продадим 50 штук». Для закупки этого мало: важно,
с какой вероятностью спрос окажется 70 или 90 штук, потому что от этого зависит риск дефицита
и списаний. Поэтому модель прогнозирует **распределение** спроса (квантили), а объём заказа
выбирается как квантиль уровня критического отношения задачи о газетчике:

$$Q^* = F^{-1}\left(\frac{C_u}{C_u + C_o}\right)$$

Агент на основе языковой модели принимает вопрос закупщика, вызывает функции прогноза
и расчёта заказа и объясняет рекомендацию. Все числа считает код, решение остаётся за человеком.

## Как запустить

```bash
git clone https://github.com/<ваш-логин>/diploma-demand-forecasting.git
cd diploma-demand-forecasting
python -m venv .venv
.venv\Scripts\activate            # Windows (macOS/Linux: source .venv/bin/activate)
pip install -r requirements.txt
python src/generate_data.py --seed 2026
```

Затем откройте `notebooks/01_eda.ipynb` в VS Code и выполните **Run All**. Ноутбук сам
пересоздаёт данные, поэтому выполняется целиком без ошибок.

## Первые результаты (Задание 1, seed = 2026)

| SKU | Среднее | Ст. откл. | ADI | CV² | Класс спроса | Эффект промо |
|-----|--------:|----------:|----:|----:|--------------|-------------:|
| SKU_A | 49,5 | 27,4 | 1,00 | 0,31 | smooth | 1,58 |
| SKU_B | 18,5 | 11,6 | 1,00 | 0,39 | smooth | 1,46 |
| SKU_C | 8,6 | 5,2 | 1,01 | 0,37 | smooth | 1,66 |
| SKU_D | 2,4 | 2,8 | 1,71 | 0,39 | **intermittent** | 1,35 |
| SKU_E | 61,0 | 32,5 | 1,00 | 0,28 | smooth | 1,59 |

- Дисперсия спроса в 3–15 раз больше среднего, поэтому распределение Пуассона не подходит
  и для спроса берём отрицательное биномиальное.
- SKU_D имеет прерывистый спрос (42 % дней без продаж): для него нужен метод Кростона/SBA, а MAPE не определена.
- Спрос в субботу в 1,47 раза выше, чем в понедельник; промо увеличивает спрос примерно в 1,6 раза.
- Для признаков модели берём лаги 7, 14, 21, 28: горизонт прогноза 7 дней, а PACF значима на лагах, кратных неделе.
